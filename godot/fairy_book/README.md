# Книга Фей — версия для Godot 4

Порт первой игры («Книга Фей», вариант А) из веб-версии на **Godot 4.3+ / GDScript**.
Механика, тексты, баланс, рисовка «под карандаш», звуки и интеграция Yandex Games SDK — такие же, как в React-версии.

## Как открыть
1. Установите Godot **4.3** или новее (стандартная сборка, не .NET).
2. В менеджере проектов нажмите «Импорт» и выберите `godot/fairy_book/project.godot`.
3. F5 — запуск. Главная сцена: `scenes/main.tscn`.

## Главы
I–V — цветочные, водяные, лунные, снежные, звёздные феи (босс — Король Теней).
Новые главы с новыми механиками:
| Глава | Феи | Механика |
|---|---|---|
| VI. Грибной хоровод | Грибные | облететь 5 грибов строго по номерам за время; пауки на паутинках, споры замедляют |
| VII. Краски радуги | Радужные | окраситься в цветке-краске и ловить пузыри своего цвета; чужой цвет — −1 |
| VIII. Первый росток | Садовые | защищать росток от гусениц и жуков и растить его солнцами |
| IX. Семена ветра | Грозовые | толкать семена в гнездо (физика толчка), уворачиваться от молний |

## Лавка фей
Пыльца начисляется в конце забега (1 ✦ за 40 очков), её можно удвоить за рекламу.
Улучшения покупаются за пыльцу **или за рекламу с вознаграждением**: крепкое сердце, быстрые крылья,
лёгкий рывок, магнит, щит из лепестков, волшебный мешочек. Хранится в `user://settings.cfg` (секция `shop`).
Код: `scripts/shop.gd`, окно — `_build_shop()` в `scripts/main.gd`.

## Режимы
| Режим | Суть | Таблица рекордов |
|---|---|---|
| ✎ Сказка | Все 5 глав подряд, после главы +1 ♥ | `user://fairy_book_scores.json` |
| ❧ Одна глава | Любая открытая глава отдельно | `user://fairy_book_chapter_scores.json` |
| ∞ Бесконечная охота | Глава без финала: враги злее, каждые 10 целей +1 ♥, Король Теней возвращается волнами | `user://fairy_book_endless_scores.json` |
| ✧ Одно перо | Сказка с одним сердцем, без лечения, очки ×2 | `user://fairy_book_hard_scores.json` |

Главы для «Одной главы» и «Бесконечной охоты» открываются по мере прохождения (хранится в `user://settings.cfg`).

Все окна (меню, описание главы, итоги, рекорды) измеряются после вёрстки и уменьшаются под экран;
на горизонтальном экране описание главы раскладывается в две колонки.

## Управление
- Клавиатура: стрелки / WASD — полёт, Пробел / Shift / J / X — рывок, Esc / P — пауза, R — заново, M — звук.
- Мышь: клик — рывок.
- Касание: веди пальцем (плавающий джойстик), кнопка «Рывок» или второй палец — рывок.

## Публикация на Яндекс Играх
1. «Редактор → Управление шаблонами экспорта» — скачайте шаблоны для своей версии Godot.
2. «Проект → Экспорт» — пресет **Web (Yandex Games)** уже настроен:
   - `Thread Support` **выключен** — Яндекс не отдаёт заголовки COOP/COEP, с потоками игра не запустится;
   - в `Head Include` подключён `/sdk.js` (относительный путь — требование модерации) и JS-мост `window.YB`.
3. Экспортируйте в `export/web/index.html`, запакуйте **содержимое** папки `export/web` в zip (index.html в корне архива).
4. Загрузите архив в Консоль разработчика, во вкладке «Реклама» подключите монетизацию.
5. Проверьте с `?debug-mode=16`: индикатор лоадера должен показывать `IT`.

### Что делает интеграция
- `LoadingAPI.ready()` — после первого кадра меню.
- `GameplayAPI.start/stop` — при игре / паузе / меню / рекламе / конце игры.
- Полноэкранная реклама — перед 2–5 главами и при «Ещё раз» (не чаще раза в минуту, частоту дополнительно ограничивает платформа). Никогда не во время геймплея.
- Реклама за награду — кнопка «Продолжить главу за рекламу» после поражения (один раз за забег): 3 сердца, очки сохраняются, прежняя запись убирается из таблицы.
- События платформы `game_api_pause/resume` ставят игру на паузу и глушат звук.
- Вне Яндекса (редактор, десктоп) SDK-вызовы — заглушки, награда выдаётся сразу для тестирования.

## Автотесты (headless)
```
godot --headless --path godot/fairy_book --editor --quit          # импорт
godot --headless --path godot/fairy_book --fixed-fps 60 res://tests/autoplay.tscn  # бот проходит все 5 глав
godot --headless --path godot/fairy_book --fixed-fps 60 res://tests/ui_flow.tscn   # все режимы, экраны, переходы + «окно помещается в экран» на 3 размерах
godot --headless --path godot/fairy_book --quit-after 3000 res://tests/endless_check.tscn  # бесконечный режим и «Одно перо»
```
